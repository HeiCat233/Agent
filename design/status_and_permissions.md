# 状态与权限矩阵（status_and_permissions.md）

> O2 工程契约的补充：定义"谁能改什么"。所有权限变更记录于本文件变更表。

## 权限矩阵

| 对象 | 查看 | 修改 | 修改约束 |
|:--|:--|:--|:--|
| 白名单（whitelist） | 全组 | 负责人（登记授权声明后） | 新增必须附来源标签+授权声明；变更记录 append-only |
| L0 拦截模式表 | 全组 | 负责人审定签字 | 每次 Red Team 后评审补充；变更进 ADR-002 变更表 |
| L1 豁免短语表 | 全组 | 负责人审定签字 | 同上 |
| L2 开关 | 全组 | 组内 Change 批准（O5 流程） | 默认关闭 |
| 置信度阈值（0.75/0.40） | 全组 | O5 Change 批准 | 禁止在评测期间临时调整 |
| 系统提示词（ai_rules.md） | 全组 | O5 Change 批准 | 变更表留痕 |
| 拦截日志（audit） | 全组只读 | 系统自动写入 | append-only，任何人（含管理员）不可删除修改 |
| 评测标注（ground truth） | 全组 | 标注人 | 修改已提交标注须在 finding_log 记录原因 |
| evidence/ 归档 | 全组只读 | 评测脚本自动写入 | 禁止手改；更正走新 run + 说明 |
| 样本 APK | 全组 | 制作人（Phase 2） | 授权声明文件随样本入库 |

## 系统运行状态

| 组件 | 正常状态 | 降级状态 | 降级行为 |
|:--|:--|:--|:--|
| Ollama LLM | 可用 | 超时/拒答 | 重试1次 → UNCERTAIN/TOOL_FAILURE，记 rejection_log |
| apktool（Docker） | 可用 | 超时/崩溃 | UNCERTAIN/TOOL_FAILURE；trace 记录容器退出码 |
| SQLite 索引 | 可用 | 损坏 | 重建索引（缓存失效），budget 不回退 |
| PreGate | 常开 | — | 无旁路：任何代码路径不得绕过 PreGate（代码评审红线） |

## 数据与隐私

- 样本与索引数据仅存本地（SQLite + 文件系统），不出网（Docker 无网络 + 全本地 LLM）；
- 会话记录含用户 query，仅本地存储，答辩展示前做脱敏检查。
