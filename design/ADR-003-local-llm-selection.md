# ADR-003：全本地 LLM 选型（决策表）

- **状态**：已接受（调试通道默认 GLM，正式可选本地——见 ADR-009）
- **日期**：2026-10-03

## 背景

- 架构前提（方案第九章）：计划器不用 LLM（规则路由），LLM 只做解释生成与可选 L2
  意图分类——因此只需一个模型，选型只看"代码理解 + 中文解释质量 vs 显存/费用"。

## 决策表

| 档位 | 方案 | 代价 | 适用 |
|:--|:--|:--|:--|
| 调试默认 | **GLM 云端 API**（OpenAI 兼容，key 用户自填） | 按 token 计费（开发调试量级≈几元）；样本出网 | 日常开发调试（无需装 Ollama，组员即可开工） |
| 正式可选 | **Qwen2.5-Coder-7B 本地**（Ollama，Q4） | 需 8G 显存（本机满足） | 离线演示/零费用场景 |
| 参考 | Qwen2.5-Coder-14B 本地 | 本机 8G 显存部分 CPU 卸载，速度需实测 | 有更强硬件时 |
| 参考 | Qwen2.5-Coder-32B 本地 | 需 24G 显存 | 不适用本机 |

模型一律使用**官方发布权重与官方 API**；不使用第三方修改权重的模型。
