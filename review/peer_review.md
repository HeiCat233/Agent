# 互审记录（peer_review.md）—— 异题互审

> A/B 两组互审。审的是对方的实现与证据，**不比较业务绝对性能**（分析对象不同）。

## 互审范围（每组四件套）

| 审查物 | 位置 | 审什么 |
|:--|:--|:--|
| 实验卡 | review/experiment_card.md | 固定条件是否真固定、放弃条件是否预先声明、负结果是否如实 |
| 负向验收 | eval/acceptance_criteria.md | R01-R08 负向用例是否真实执行、期望状态是否与 ADR-004 一致 |
| 失败案例 | evidence/failures/ + review/finding_log.md | 失败是否被掩盖、根因区分事实/推断、wontfix 是否有理由 |
| 交接包 | release/ | 干净环境按 RUNNING.md 能否恢复（执行记录填 recovery_test.md） |
