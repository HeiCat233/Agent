## 评测执行规范

1. 每次评测 = 一个 run（evidence/run_XXX/），含 input.json / output.json / trace.log / cost.json；
2. 评测脚本与版本固定，记录在 evidence/version_manifest.json；
3. 分歧仲裁规则：双评不一致时抽 20% 人工仲裁，仲裁人=标注者以外的人；
4. 未达标处理：如实记录 → finding_log.md 建项 → 归因（数据/模型/规则）→ 修复后新 run 重测，
   保留失败 run 不删除（O3 要求）。
