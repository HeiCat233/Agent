# B组技术方案：小程序分析 Skill（miniprogram-analysis）

> B组差异化实现。**契约与 A组完全一致**（agent 的 Contracts.java / 状态机 / reason_code /
> 双关卡），本文件只定义"分析器内部"的差异。目标类型 `target_type=MINIPROGRAM`。

## 一、Stage 1 解包（对应 A组 apktool decode）

- 输入：微信 PC 端小程序包 `*.wxapkg`（主包 `__APP__` / 子包）；
- 工具建议：开源解包器（unveilr / wuWxapkg 生态）或自实现 wxapkg 头解析（文件头含
  magic/索引段/数据段，V1MMWX 加密包需先解密——PC 包常见）；
- 产物目录：`app.json`、`app.js`、`pages/**`（.js/.wxml/.wxss/.json 四件套）、
  `components/**`、`utils/**`、`project.config.json`；
- 组件清单等价物（FR-03）：解析 `app.json` 的 `pages`/`subpackages`/`usingComponents`
  与各页 `.json` 的 `usingComponents` → 页面/组件清单。

## 二、Stage 2 索引（对应 smali 索引）

| 表 | 内容 | 解析方式 |
|:--|:--|:--|
| pages | 路径/标题(windownavigationBarTitleText)/是否分包 | app.json JSON 解析（确定性） |
| js_functions | 函数名/所属文件/起止行号/参数个数 | JS 解析：建议 acorn/esprima AST（Node）或正则 `function\s+(\w+)\s*\(` + 箭头函数 + Page({method}) 对象方法 |
| wxml_bindings | 事件绑定（bindtap→处理函数）/插值变量 | WXML 正则（`bind\w+="handler"`） |
| api_calls | wx.* 调用与所属函数 | AST callExpression callee 匹配 `wx.\w+` |
| strings | JS 字符串字面量（URL/key/明文 token） | AST literal |

> 技术栈建议：Node + acorn（AST 稳定，函数行号天然准确）或 Python + esprima-python。
> 契约与核心由 A组提供，语言 B组自选——这是 ADR-006 的设计意图。

## 三、Stage 3 定位（对应 A组三策略）

1. **页面路由反查**：query 中页面名/中文标题 → pages 表反查 → 该页 js 的函数；
2. **API 指纹**（等价 A组指纹库）：
   - "登录" → `wx.login` + `wx.getUserProfile` + `code2Session`
   - "支付" → `wx.requestPayment` + `wx.request`
   - "存储" → `wx.setStorageSync` / `wx.getStorageSync`
   - "网络" → `wx.request`（含未校验域名问题）
   - "位置" → `wx.getLocation`
3. **入口**：`app.json` 首页 + tabBar 列表。

## 四、Stage 4-6：证据提取 / 受限解释 / 回验

- 片段：JS 函数体（file:line 范围）+ 关键 WXML 片段；≤200 行规则与 A组一致；
- 解释：**同一份 ai_rules.md 四条铁律 + `<untrusted_code>` 数据包裹**（共享核心注入，
  B组不改提示词）；
- 回验：LLM 引用 file:line 必须存在于提取片段——机制与 A组相同（PostGate Q2 统一兜底）。

## 五、FR-09 对应物：pages 注释树

规则骨架（pages 列表/组件依赖深度/tabBar 结构）+ LLM 仅做页面级用途注释（数据包裹）+
混淆/压缩 js 的推断标注 `inference=true` + 关键路径高亮（首页/tabBar/支付页/含
`wx.request` 的页面）。输出 Markdown 可导出。

## 六、评测样本（B组自备，规范对齐 eval/dataset_plan.md）

自研教学小程序 ×N（植入模式 ground truth 已知）：登录页明文 appsecret、未校验 request
域名、明文 storage 存 token、页面路由未鉴权；**至少 1 个样本植入 prompt 注入串**（T1）。
开源模板 ×2（保留 License）。混淆样本（代码压缩）专测 UNCERTAIN。
